Local images used for the hero, gallery, tour cards, and seed data. Sources: [Wikimedia Commons](https://commons.wikimedia.org/) (free licenses).

| File | Subject |
|------|---------|
| `hero-ichan-kala.jpg` | Ichan Kala, Khiva |
| `khiva-kalta-minor.jpg` | Kalta Minor, Khiva |
| `kunya-ark.jpg` | Kunya Ark, Ichan Kala |
| `ayaz-kala.jpg` | Ayaz Kala fortress |
| `ayaz-kala-oasis.jpg` | Ayaz Kala, Kyzylkum |
| `toprak-kala.jpg` | Toprak Kala ruins |
| `aral-moynaq.jpg` | Moynaq ship cemetery, Aral Sea |

Re-download missing files:

```bash
npm run images:download
```

After updating images in the database, run:

```bash
npm run seed
```
